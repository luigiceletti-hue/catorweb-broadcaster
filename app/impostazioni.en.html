❓ Help: how to fill in this page

🌐 Lingua / Language

📻 The radio

Name and genre are sent to the server and appear in the listeners' players.

📡 Streaming server

The details your streaming provider gave you (Icecast / Shoutcast / Centova / AzuraCast panel…).
Don't have them yet? Leave the address empty: you can use everything in 🎧 Rehearse (the radio plays only on this PC) and enter them when you get them.
Shoutcast: enter the server's public port (the app connects to port + 1 by itself). For Shoutcast v2 with several streams the password can be in the form password:#1.

📁 Folders

Music to broadcast, library database, ⏺ REC recordings and playlist exports.

🎙 Microphone

The microphone to talk on air. If you don't use one leave "No microphone".
The voice processor (compressor, de-esser, limiter) is always on; here you only set the pitch and body of the voice. In 🎧 Rehearse you hear the change right after saving.

✨ Extra

In the 🎛 Studio tab, below the next track, Claude writes 2-3 sentences to read on the mic using the track's information.
How to turn it on
  1. You need a Claude account with a plan (Pro or Max): the free plan doesn't include Claude Code.
  2. Install Claude Code: open PowerShell (Start menu → type "PowerShell"), paste this line and press Enter:
    irm https://claude.ai/install.ps1 | iex
  3. Connect it to your account: in the same window type claude and press Enter. The browser opens: sign in with your Claude account and authorise. Then type /exit and close PowerShell.
  4. Close and reopen Catorweb Broadcaster. Above it should say "✓ Claude Code found"; in the Studio, below the next track, you get ✍ Suggest intro.
If the installer asks for Git for Windows, download it from git-scm.com and install it with the suggested options. Each intro uses a small part of your Claude plan's usage limits.
At start-up it only asks GitHub for the latest version number.
